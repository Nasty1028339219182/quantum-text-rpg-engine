Как начать
==========

Два файла в релизе. Это не два редактора.

QuantumRPG.exe
  Это и игра, и редактор. Python не нужен.
  1. Если Windows пишет «Защитник Windows предотвратил запуск»,
     нажми «Подробнее», затем «Выполнить в любом случае».
  2. Откроется окно со списком: Седой Брод, Тень крепости, Первые шаги.
  3. Выбери игру и нажми «Играть».
  4. «Редактор» открывает ту же игру для правки.
  5. «Новая игра» создаёт свою пустую игру.
  Если окно не открылось, рядом с exe появится файл QuantumRPG-error.log.
  Пришли его текст.

quantum-rpg-author-....zip
  Это исходники. Отдельного exe внутри нет, и не должно быть.
  Игры лежат папками, их не запускают двойным щелчком:
    games\greyford        Седой Брод
    games\shadow_keep     Тень крепости
    games\first_steps     Первые шаги
    games\template        пустая игра
  Нужен Python 3.10 или новее с галочкой Add python.exe to PATH.
  Потом в этой папке:
    pip install -r requirements.txt
    ИГРАТЬ.bat
  То же окно, что и у exe: список, «Играть», «Редактор».
