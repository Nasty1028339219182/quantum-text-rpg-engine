# Player commands

The parser accepts English and Russian. Directions can be typed alone (`n`, `север`).

| Action | English | Russian |
|---|---|---|
| Look | look, l, examine | осмотреться, осмотреть |
| Go | go north, n, north | идти север, с, север |
| Take | take, get | взять, поднять |
| Drop | drop | положить, выбросить |
| Use | use, drink | использовать, выпить |
| Equip | equip, wear | надеть |
| Unequip | unequip | снять |
| Inventory | inventory, i | инвентарь |
| Talk | talk, ask | говорить, спросить |
| Attack | attack, kill | атаковать, ударить |
| Search | search | искать, обыскать |
| Open | open | открыть |
| Read | read | читать |
| Give | give | дать |
| Shop | shop, buy, sell | лавка, купить, продать |
| Craft | craft | создать, варить |
| Combine | combine | соединить |
| Stats | stats, sheet | характеристики, я |
| Quests | quests | задания |
| Journal | journal | журнал |
| Map | map | карта |
| Rest | rest | отдохнуть |
| Wait | wait | ждать |
| Save/load | save, load | сохранить, загрузить |
| Language | language ru\|en | язык ru\|en |
| Say | say | сказать, произнести |
| Help | help, ? | помощь |
| Quit | quit, exit | выход |

In combat: `1` attack, `2` item, `3` defend, `4` flee.

In dialogue: type `1`, `2`, … or `уйти` / `leave`.
