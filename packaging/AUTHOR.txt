Quantum Text RPG — author pack
==============================

Read КАК_НАЧАТЬ.txt first. This zip has no exe. QuantumRPG.exe is the
other file in the release: it already plays and edits the bundled games.

You (author), if you want the source:
  1. Install Python 3.10+ and tick Add python.exe to PATH
  2. pip install -r requirements.txt
  3. ИГРАТЬ.bat
     python -m quantum_rpg editor greyford

Games are folders, not programs:
  games\greyford       Седой Брод
  games\shadow_keep    Тень крепости
  games\first_steps    Первые шаги
  games\template       empty game
